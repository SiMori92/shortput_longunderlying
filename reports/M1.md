# M1 — Scaffold accepted

18 Nov 2026. Stopped at M1 as requested. M2–M8 are not implemented.

## Built

- Next.js 16.4.6 App Router, React 19.3.1, strict TypeScript, pnpm lockfile, Tailwind 4 and lucide-react.
- Deep-green responsive placeholder, collapsible desktop sidebar, mobile bottom navigation, stacked inventory cards, accessible formula disclosures, manifest and PNG icons.
- Zod schemas for bars, underlying/rule config, Yahoo responses, run files, portfolio, journal and API boundaries. Future-run schemas exist; no synthetic final runs are written.
- Atomic JSON write/rename storage. Existing data survives restart; corrupt data fails closed. Root `/data/` is ignored without accidentally ignoring `src/data/` or `tests/data/`.
- Six bundled source CSVs with recorded SHA-256 provenance. All six verified byte-identical to original files. `Backtest/`, `Strategy/`, the plan and original prompt remain unchanged.
- Startup seeding and once-per-process ET schedule registration via instrumentation. Cron callbacks are explicitly blocked until M2/M3; no market fetch, trade or account value is fabricated.
- Health endpoint, provider interface stubs, `.env.example`, startup and verification instructions.

## Deviations / staged limitations

The M1 inventory uses a native table and native disclosures instead of shadcn/TanStack components; no complex interaction needs them yet. Rationale is in README. Actual calendar-gated jobs are M3, and auth is M8, per the milestone order. Both run commands bind to loopback pending auth. This scaffold must not be publicly deployed. No engine/parity, actionable run, live freshness certification or working strategy page is claimed at M1.
