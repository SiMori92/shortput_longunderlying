Stored overlap values are preserved; rejected updates do not replace that symbol's bars. Any configured symbol validation failure blocks recommendations.

Coverage beyond 2028 fails closed pending review.
- Preview uses a fresh Yahoo live quote as a provisional close in memory only. A final rejects today's partial bar before 16:15 ET unless same-day session metadata says the regular session ended. Prior-day metadata cannot authorize today's bar. Cboe midnight-UTC daily date labels retain their date; their extra non-NYSE observations are allowed as reference inputs.
- Three real calendar-gated cron jobs registered by instrumentation: 15:40 preview, 16:20 final and 07:00 catch-up, all ET. No immediate network request is required at startup. Cross-trigger run locking protects server writes; holidays skip and catch-up skips a valid previous-session final.
- RunResult assembly through shared M2 engine functions, including gate distances, preview close calls, current manual NAV, observed-snapshot drawdown/kill, next-close core estimates, model put sizing/limits/credit, rounded quantities, open-put actions, numeric working entries and preview differences. No current snapshot means no account or trade suggestions. SPAX remains monitor only, with qualification inputs deferred to M6.
- Atomic run files, per-symbol update diagnostics, failed attempt files, last-attempt banner, newest valid final pointer, and nightly full V3.1/archived replays with monthly/yearly returns. Failed runs preserve prior valid finals; old manual reruns cannot roll back latest/replay. Replay failure prevents final promotion and writes a blocked status so catch-up can recover after repair.
- Auth-protected GET/POST `/api/runs`, strict bounded JSON input, same-origin POST check, signed/TOTP-completed/expiring owner-session verification and schema-safe errors. Missing secrets/auth fail closed. M8 still supplies actual password/TOTP login and cookie issuance; there is no temporary bypass.
- A wired Run now button, local `pnpm run:now` command, responsive validation banner, symbol freshness chips, preview/final differences, and explicit unknown SPAX facts. The full Today/Gate/Puts visualization remains M4.
- No new dependencies. Native Intl supplies ET/DST conversion; the NYSE calendar is an auditable bounded module. README explains this choice and the required annual review.

## Deviations / staged limits

- Full login and page protection remain M8 as specified by the milestone order. The M3 run API already fails closed; the button cannot initiate a remote run before a valid login session exists. The local CLI supports job operation in the interim. Server remains bound to loopback.
- Gate/core/account blocks may be null when inputs are unconfirmed or invalid, rather than encoding fabricated numeric placeholders. Structured issue records supply actionable banners.
- The first production-source runs are intentionally blocked. Healthy lifecycle acceptance is proven by deterministic integration tests; a real actionable final is **not** claimed.
- Calendar coverage is explicitly bounded to 2028. Holidays and early closes beyond that need review. No outside calendar service or unverified indefinite future schedule is assumed.
- One process owns each data directory. In-process locking plus per-file atomic writes does not support multiple replicas or concurrent server/CLI writers. This is documented and consistent with the single long-running Node deployment target.
- Numeric working and live model assembly are present in run JSON; the full financial UI, position/journal consistency, SPAX qualification, Backtest/Rules UI and password/TOTP setup remain their later milestones.
