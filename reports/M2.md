# M2 — Engine and parity accepted

18 Nov 2026. Stopped at M2. M3–M8 remain pending.

## Built

- Pure framework-free TypeScript in `src/engine/`: feature joins/warm-up, sample RV, IV/skew, double-precision Cephes CDF, Black-Scholes puts/delta/strike solver, both gates, core/put sizing, commissions, put lifecycle, daily state transition, replay, metrics and monthly/yearly returns.
- Shared `stepDay` for replay and future daily runs. No I/O or framework imports. Expiries are supplied by the caller. Fractional replay quantities and whole-contract/share helpers remain separate. The live kill overlay suppresses new risk at −25%; replay remains unchanged.
- `tools/export_fixtures.py` imports original Python read-only and instruments its loop to observe daily values/core trades/positions. V3.1 gate substitution is applied locally; `riskcut_v3.py` is never imported. The instrumented archive is asserted equal to unmodified `run3` output.
- `pnpm fixtures:export` creates a fresh ignored Python 3.13 venv through uv, installs pinned pandas/NumPy/SciPy and executes the exporter with `uv run`. Original Python bytecode writes are disabled.
- Committed independent Python fixtures: 3,999 feature rows, two 2,231-day replays, all closed puts, every daily core trade, gates/targets/positions, metrics, monthly/yearly returns and numerical edge cases. Zod validates fixture/result boundaries. Provenance stores source and CSV SHA-256 hashes; tests verify bundled seed identity. All three original Python source hashes were rechecked unchanged.
- `pnpm build` runs parity before Next.js compilation. Python is needed only to regenerate fixtures; ordinary install/test/build works with WebApp alone.
- README documents architecture, fixture regeneration, exact quirks, tolerances and staged limitations. Cephes attribution/license is in `THIRD_PARTY_NOTICES.md`.
