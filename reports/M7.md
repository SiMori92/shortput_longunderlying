## Interpretations, deviations and limits

1. No real nightly pair currently exists, because existing live-data blockers prevent final promotion. A read-only, server-side seed replay keeps M7 usable, labelled **Seed-history replay · no validated nightly pair**. It uses the existing start/capital and shared engine; it never promotes a live final or writes into the nightly result slots.
2. SOXL comparison is normalized raw-price buy-and-hold, excludes fees/distributions, and has its own drawdown peak. Equity defaults to a visibly labelled log scale to preserve the visibility of strategy growth beside SOXL spikes; linear remains available.
3. Python first-period convention is preserved: first observed equity, then previous period close. Missing periods are not filled with zero. Final periods are not annualized. The displayed two-decimal CAGR naturally differs in precision from the brief's one-decimal reference.
4. Existing nightly files lack a rule-config fingerprint and historical RF inputs. The page warns that current Rules settings do not certify an older snapshot's settings. Stored Sharpe remains the stored validated numeric metric, while its absent historical mean-excess input is explicitly unconfirmed; the loader does not invent an RF series from a changed cache.
5. Tables switch to stacked/grid rows on narrow screens; the monthly heatmap changes layout below 1100px so month values and 44px working targets remain readable without horizontal page scrolling.
6. M8 still owns login issuance, full page/read-route authentication, Docker and deployment. Loopback binding remains. Existing SOXX split and missing ^IRX-session blockers still suppress live actions; no exception was added.
